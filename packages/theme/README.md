# @yadad/theme

The yadad token contract: `TOKEN_NAMES` (the owned list, each becoming a `--yadad-<name>` CSS variable), the `Theme` type, the light and dark token sets, and `themeToCss` — the CSS-variable emitter. No dependencies.

Token names are the contract; values are free to change. See the repo [README](https://github.com/aggressive-stag/yadad) and [ARCHITECTURE.md](https://github.com/aggressive-stag/yadad/blob/main/ARCHITECTURE.md) for the design.
