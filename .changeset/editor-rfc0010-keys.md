The editors write the RFC 0010 keys. A quick filter row takes a label, a placeholder (text filters only) and a first value of the kind the filter takes. The table editor has "Make column not sortable" per column and "Not sortable (every column)" for the table; a sort that names an unsortable column is refused. The field editor has a "Set by the server (read-only)" toggle. The condition builder offers "Hours from now" for datetime fields with the comparing operators, writing `{ "hoursFromNow": n }`.
